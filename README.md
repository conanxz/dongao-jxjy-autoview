# 东奥自动看课 v2.1.0（浙江会计继续教育）

> 浙江会计继续教育（东奥平台）自动看课答题油猴脚本。
> 自动完成课程学习与答题，全程单标签运行，纯前端脚本，无需服务器。

## 功能特性

- **自动看课答题**：进入课程后自动播放视频、自动完成随堂答题，全程无需手动操作
- **全程单标签**：整个学习过程只在当前标签内完成，不弹出多余窗口，不干扰其他工作
- **自动登录识别**：自动识别登录状态，登录过期自动恢复，无需反复手动登录
- **浙里办暂停等待**：识别到浙里办（浙江政务服务）登录页时自动暂停，等你登录后自动继续
- **自动顺序切课**：一门课学完自动进入下一门，支持课程/讲次列表自动翻页
- **看课进度实时显示**：悬浮窗实时显示当前进度、运行状态、运行日志
- **视频黑屏自愈**：视频加载失败、黑屏卡死时自动重试恢复，尽量不中断学习
- **会话保活**：自动轻触页面防掉线，长时间挂机也稳定
- **一键导出日志**：内置运行日志，点一下复制到剪贴板，方便远程排查问题

## 环境要求

- 浏览器：Microsoft Edge / Google Chrome（或其他 Chromium 内核浏览器）
- 扩展：Tampermonkey（篡改猴）v5.0+
- 适用平台：浙江会计继续教育网（东奥平台）—— jxjy.czt.zj.gov.cn / study.dongao.cn 等

## 安装步骤

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 新建用户脚本，粘贴 `东奥自动看课v2.1.0.user.js` 的全部代码，保存
   （或在脚本列表页导入该 .user.js 文件）
3. 确保脚本处于**启用**状态
4. 打开浙江会计继续教育网，登录后进入学习页面，脚本会自动开始

> 首次使用建议观察前几分钟，确认脚本正常自动播放后再挂机。

## 使用说明

### 悬浮窗操作

运行时会有一个悬浮窗显示状态：

- **⏸ 暂停 / ▶ 继续**：随时暂停或恢复自动学习
- **🔄 重置**：清空当前进度，重新开始
- **📋 导出日志**：把运行日志复制到剪贴板（用于排查问题，见下节）

### 导出日志（排查问题）

如果遇到脚本异常，点悬浮窗的 **📋 导出日志**，日志会自动复制到剪贴板，直接粘贴发给我或开发者即可。导出内容包含：

- 脚本版本、运行时间、当前页面地址
- 浏览器 UA、账户信息
- 完整运行日志时间线（登录、进课、播放、答题、切课、异常恢复等）

> 日志保存在浏览器 localStorage 中（环形缓冲，固定保留最近 500 条，不会无限增长），导出采用复制到剪贴板方式，**不产生任何本地文件**。

## 常见问题

**Q：视频黑屏/不播放怎么办？**
脚本内置黑屏自愈，会自动尝试恢复。若长时间未恢复，可手动刷新页面重新进入该课程。

**Q：没有自动答题？**
确认已登录、脚本已启用，且当前页为东奥学习页面。可在悬浮窗日志中查看是否有异常记录。

**Q：登录页卡住不动？**
脚本识别到浙里办登录页时会暂停等待，请完成登录，登录后会自动继续。
