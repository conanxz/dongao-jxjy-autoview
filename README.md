# 东奥继续教育自动挂课脚本

> 会计继续教育（东奥网校）自动看课答题油猴脚本，纯前端、无需服务器、全程单标签。
> 现提供两个版本：**全国通用版** 与 **浙江专用版**，按需二选一安装。

## 版本怎么选

| | 全国通用版 | 浙江专用版 |
|---|---|---|
| 文件 | `jxjy-autoview.user.js` | `zj-jxjy-autoview.user.js` |
| 适用范围 | 任何登录后进入东奥网校（study.dongao.cn）的省份 | 浙江会计继续教育 |
| 登录方式 | 各省门户登录一律人工，脚本不干预 | 含浙江门户跳转链、登录识别、浙里办暂停等待 |
| 自动挂课核心 | ✅ | ✅ |

> 两个脚本**不要同时启用**（作用域重叠会互相干扰）。

## 功能特性（两版共有核心）

- **自动看课答题**：进入课程后自动播放视频、自动完成随堂答题，全程无需手动操作
- **自动顺序切课**：一门课学完自动进入下一门，支持课程/讲次列表自动翻页
- **全程单标签**：整个学习过程只在当前标签内完成，不弹出多余窗口
- **视频黑屏自愈**：视频加载失败、黑屏卡死时分步自动恢复，尽量不中断学习
- **超时弹窗自愈**：检测到「听课页面已超时」弹窗时自动返回课程页重进（不点「退出听课」，避免关网页）
- **会话保活**：每 5 分钟轻触学习页防 idle 掉线，长时间挂机也稳定
- **学分总进度**：悬浮窗显示总进度百分比（已学学分 / 总学分，回到「我的课程」页自动统计）
- **运行日志一键导出**：点一下复制到剪贴板，方便排查问题；日志环形缓冲固定 500 条，不产生任何本地文件

## 浙江专用版额外功能

- **自动登录识别**：自动识别登录状态，登录过期自动恢复
- **浙里办暂停等待**：识别到浙里办登录页时自动暂停，登录后自动继续
- **浙江门户跳转链**：从 jxjy 门户自动走完选课入口到网校学习页

## 版本号规则（3.0.0 起）

- **第一位**：质变大版本（3.0.0 = 从浙江专用扩展为全国通用）
- **第二位**：挂课核心的共性修复/增强，两个脚本一起改、一起升（如 3.1.0）
- **第三位**：单个版本的专属修复，只改对应脚本（如 3.0.1）

当前版本：全国通用版 3.0.0 / 浙江专用版 3.0.0

## 环境要求

- 浏览器：Microsoft Edge / Google Chrome（或其他 Chromium 内核浏览器）
- 扩展：Tampermonkey（篡改猴）v5.0+
- 平台：东奥网校（study.dongao.cn 等东奥域名）

## 安装步骤

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 在脚本列表页导入对应版本的 `.user.js` 文件（或新建脚本粘贴代码保存）
3. 确保脚本处于**启用**状态
4. 从本省继续教育门户登录进入东奥网校，脚本会自动开始

> 首次使用建议观察前几分钟，确认脚本正常自动播放后再挂机。

## 匹配地址

- **浙江专用版**：`*://jxjy.czt.zj.gov.cn/*`、`*://*.dongao.cn/*` 等

## 使用说明

### 悬浮窗操作

- **⏸ 暂停 / ▶ 继续**：随时暂停或恢复自动学习
- **🔄 重置**：清空当前进度，重新开始
- **📋 导出日志**：把运行日志复制到剪贴板（用于排查问题）

### 导出日志（排查问题）

遇到脚本异常时，点悬浮窗的 **📋 导出日志**，日志自动复制到剪贴板，粘贴发给开发者即可。导出内容包含脚本版本、当前页面、UA、账户、完整运行日志时间线（进课、播放、答题、切课、异常恢复等）。

## 常见问题

**Q：视频黑屏/不播放怎么办？**
脚本内置黑屏自愈会自动尝试恢复。若长时间未恢复，可手动刷新页面重新进入该课程。

**Q：挂到一半提示「恢复失败已暂停」？**
说明登录态可能已失效。重新登录本省门户进入网校后，点悬浮窗「▶ 继续」即可。

**Q：学到 90 分提示完成后还会继续学吗？**
会。90 分是达标提示不是停止线，脚本会把已选的课全部挂完；不需要继续的话手动暂停即可。

**Q：进度条显示异常（空白/看不到时间）？**
个别页面存在播放器 UI 与播放状态脱钩的情况（视频实际在正常播放），不影响学习，刷新页面可恢复显示。
